GREJA – INSTALLERBAR TESTAPP

1. Ladda upp alla filer och mappen icons till samma katalog på en HTTPS-webbplats (t.ex. GitHub Pages).
2. Öppna webbadressen i Safari på iPhone.
3. Tryck Dela och välj Lägg till på hemskärmen.

OBS: Att öppna index.html direkt från Filer/ChatGPT installerar inte en PWA.
Uppgifter sparas lokalt på den aktuella enheten/webbläsaren, utan konto eller molnbackup.
Typsnittet Quicksand hämtas från Google Fonts vid internetanslutning; reservtypsnitt används offline om fonten inte laddats.
